## 📖 Введение

**Expense Chart** - это профессиональное графическое приложение для управления личными финансами, разработанное с использованием Python и библиотек tkinter и matplotlib. Приложение предоставляет интуитивно понятный интерфейс для ведения учета расходов, их категоризации и визуализации.

### 🎯 Цели создания

1. **Упрощение учета расходов** - интуитивный интерфейс для быстрого добавления и просмотра трат
2. **Визуализация данных** - наглядное представление структуры расходов через графики
3. **Анализ бюджета** - возможность фильтрации и подсчета сумм по категориям
4. **Безопасность данных** - автоматическое сохранение и резервное копирование
5. **Кроссплатформенность** - работа на Windows, macOS и Linux

### 👥 Целевая аудитория

- **Частные лица** - для контроля личного бюджета
- **Семьи** - для ведения семейного бюджета
- **Фрилансеры** - для учета профессиональных расходов
- **Студенты** - для планирования бюджета
- **Малый бизнес** - для учета операционных расходов

## ✨ Ключевые особенности

### 📋 Управление данными

| Функция | Описание | Преимущества |
|---------|----------|--------------|
| **Добавление расходов** | Быстрое добавление с указанием суммы, категории и даты | Интуитивный диалог, поддержка Enter |
| **Редактирование** | Возможность изменения существующих записей | Гибкость управления данными |
| **Удаление** | Удаление отдельных записей или всех данных | Очистка и поддержка актуальности |
| **Просмотр** | Таблица с полной информацией о расходах | Удобная навигация и сортировка |

### 🔍 Фильтрация и поиск

| Фильтр | Описание | Пример использования |
|--------|----------|---------------------|
| **По категории** | Показывает расходы выбранной категории | Только "Еда" за последнюю неделю |
| **По периоду** | Фильтрация по диапазону дат | Расходы за июнь 2026 |
| **Комбинированный** | Одновременная фильтрация по категории и периоду | Расходы на транспорт в мае |

## 🚀 Установка

### Быстрая установка

#### Способ 1: Автоматический установщик

**Windows:**
```cmd
1. Откройте командную строку (Win + R → cmd)
2. Перейдите в папку с проектом:
   cd C:\путь\к\папке\expense_chart_gui
3. Запустите установку:
   python install.py
4. Следуйте инструкциям на экране
```

**macOS/Linux:**
```bash
1. Откройте терминал
2. Перейдите в папку с проектом:
   cd /путь/к/папке/expense_chart_gui
3. Запустите установку:
   python3 install.py
4. Следуйте инструкциям на экране
```

#### Способ 2: Установка через pip

```bash
# Установка зависимостей
pip install matplotlib

# Запуск приложения
python main.py
```
