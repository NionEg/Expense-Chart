## Введение

**Expense Chart** - это профессиональное графическое приложение для управления личными финансами, разработанное с использованием Python и библиотек tkinter и matplotlib. Приложение предоставляет интуитивно понятный интерфейс для ведения учета расходов, их категоризации и визуализации.

### Цели создания

1. **Упрощение учета расходов** - интуитивный интерфейс для быстрого добавления и просмотра трат
2. **Визуализация данных** - наглядное представление структуры расходов через графики
3. **Анализ бюджета** - возможность фильтрации и подсчета сумм по категориям
4. **Безопасность данных** - автоматическое сохранение и резервное копирование
5. **Кроссплатформенность** - работа на Windows, macOS и Linux

### Целевая аудитория

- Частные лица - для контроля личного бюджета
- Семьи - для ведения семейного бюджета
- Фрилансеры - для учета профессиональных расходов
- Студенты - для планирования бюджета
- Малый бизнес - для учета операционных расходов

## Подробное руководство

### Главное окно

Главное окно приложения состоит из нескольких зон:

#### 1. Строка меню
```
Файл    Графики    Помощь
```

**Файл:**
- Добавить расход - открыть диалог добавления
- Экспорт в JSON - сохранить данные в файл
- Импорт из JSON - загрузить данные из файла
- Очистить все данные - удалить все записи
- Выход - закрыть приложение

**Графики:**
- Круговая диаграмма - показать распределение по категориям
- Столбчатая диаграмма - показать суммы по категориям
- Динамика расходов - показать график динамики

**Помощь:**
- О программе - информация о версии и авторе

#### 2. Панель фильтров
```
Категория: [Все]  Дата с: [2026-06-01]  по: [2026-06-24]
[Сбросить фильтры]  [Добавить расход]
```

- **Категория** - выпадающий список для фильтрации по категории
- **Дата с** - поле для начальной даты (ГГГГ-ММ-ДД)
- **по** - поле для конечной даты (ГГГГ-ММ-ДД)
- **Сбросить фильтры** - показать все записи
- **Добавить расход** - открыть диалог добавления

#### 3. Строка статистики
```
Всего записей: 15 | Общая сумма: 12,500.00 руб.
```

Отображает общее количество записей и их сумму с учетом текущих фильтров.

#### 4. Таблица расходов
```
+----+------------+-----------+----------+------------------+
| №  | Дата       | Категория | Сумма    | Доп. информация  |
+----+------------+-----------+----------+------------------+
| 1  | 2026-06-24 | Еда       | 500.00   | Место: Магнит    |
+----+------------+-----------+----------+------------------+
```

Отображает все расходы с возможностью сортировки по колонкам.

#### 5. Панель действий
```
[Удалить] [Круговая] [Столбчатая] [Динамика] [Обновить]
```

- **Удалить** - удалить выбранную запись
- **Круговая** - показать круговую диаграмму
- **Столбчатая** - показать столбчатую диаграмму
- **Динамика** - показать график динамики
- **Обновить** - обновить данные в таблице

### Добавление расходов

#### Способ 1: Через кнопку "Добавить расход"

1. Нажмите кнопку **"Добавить расход"**
2. Заполните диалоговое окно:

**Обязательные поля:**

- **Сумма**: Введите положительное число (например: 100, 250.50, 1000.00)
- **Категория**: Выберите из списка (Еда, Транспорт, Развлечения, Другое)
- **Дата**: Введите в формате ГГГГ-ММ-ДД (например: 2026-06-24)

**Опциональные поля:**

- **Дополнительно**: Введите дополнительную информацию:
  - Для "Еда" - место покупки
  - Для "Транспорт" - тип транспорта
  - Для "Развлечения" - описание
  - Для "Другое" - комментарий

3. Нажмите **"Добавить"** или клавишу **Enter**

#### Способ 2: Через меню

1. Нажмите **"Файл"** -> **"Добавить расход"**
2. Заполните диалоговое окно
3. Нажмите **"Добавить"**

### Просмотр расходов

#### Таблица расходов

Таблица содержит следующие колонки:

| Колонка | Описание | Формат | Пример |
|---------|----------|--------|--------|
| № | Порядковый номер | Число | 1 |
| Дата | Дата расхода | ГГГГ-ММ-ДД | 2026-06-24 |
| Категория | Категория расхода | Строка | Еда |
| Сумма | Сумма расхода | Число (2 знака) | 500.00 |
| Доп. информация | Дополнительные данные | Строка | Место: Магнит |

#### Сортировка

Для сортировки по колонке:
1. Нажмите на заголовок колонки
2. Данные отсортируются по возрастанию
3. Нажмите еще раз для сортировки по убыванию

### Фильтрация

#### Фильтрация по категории

1. Найдите выпадающий список **"Категория"** в панели фильтров
2. Выберите категорию:
   - **Все** - показать все категории
   - **Еда** - только расходы на еду
   - **Транспорт** - только транспортные расходы
   - **Развлечения** - только расходы на развлечения
   - **Другое** - только прочие расходы
3. Таблица автоматически обновится

#### Фильтрация по периоду

1. В поле **"Дата с"** введите начальную дату
2. В поле **"по"** введите конечную дату
3. Таблица автоматически обновится

**Формат даты:** ГГГГ-ММ-ДД

#### Комбинированная фильтрация

Можно комбинировать фильтры по категории и периоду.

#### Сброс фильтров

Нажмите кнопку **"Сбросить фильтры"**.

### Удаление записей

#### Удаление одной записи

1. Выберите запись в таблице (кликните по ней)
2. Нажмите кнопку **"Удалить"**
3. Подтвердите удаление

#### Удаление всех данных

1. В меню выберите **"Файл"** -> **"Очистить все данные"**
2. Подтвердите удаление

### Визуализация данных

#### Круговая диаграмма

Показывает распределение расходов по категориям в процентах.

**Как использовать:**
1. Нажмите кнопку **"Круговая диаграмма"**
2. Откроется новое окно с диаграммой

**Когда использовать:**
- Для быстрого анализа структуры бюджета
- Для определения основных статей расходов
- Для сравнения долей категорий

#### Столбчатая диаграмма

Сравнивает суммы расходов по категориям.

**Как использовать:**
1. Нажмите кнопку **"Столбчатая диаграмма"**
2. Откроется новое окно с диаграммой

**Когда использовать:**
- Для точного сравнения сумм по категориям
- Для определения самой затратной категории
- Для визуализации бюджетных приоритетов

#### График динамики

Отображает изменение расходов во времени.

**Как использовать:**
1. Нажмите кнопку **"Динамика"**
2. Откроется новое окно с графиком

**Когда использовать:**
- Для отслеживания ежедневных трат
- Для выявления пиковых дней расходов
- Для анализа изменений в расходах

### Управление данными

#### Автоматическое сохранение

- После каждого добавления или удаления записи данные автоматически сохраняются
- Данные хранятся в `data/expenses.json`
- Создается резервная копия в `data/expenses.json.backup`

#### Экспорт данных

1. В меню выберите **"Файл"** -> **"Экспорт в JSON"**
2. Выберите папку и укажите имя файла
3. Нажмите **"Сохранить"**

#### Импорт данных

1. В меню выберите **"Файл"** -> **"Импорт из JSON"**
2. Выберите файл с данными
3. Нажмите **"Открыть"**

## Устранение проблем

### Проблема: "No module named 'tkinter'"

**Windows:**
```cmd
# Обычно tkinter уже установлен
# Если нет - переустановите Python с опцией "Install tcl/tk"
```

**macOS:**
```bash
brew install python-tk
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt-get install python3-tk
```

**Linux (Fedora/RHEL):**
```bash
sudo dnf install python3-tkinter
```

### Проблема: "No module named 'matplotlib'"

```bash
# Установка matplotlib
pip install matplotlib

# Для Python 3
pip3 install matplotlib

# Переустановка
pip install matplotlib --force-reinstall
```

### Проблема: Графики не отображаются

```bash
# Проверка бэкенда
python -c "import matplotlib; print(matplotlib.get_backend())"

# Если бэкенд не TkAgg, установите его
python -c "import matplotlib; matplotlib.use('TkAgg')"
```

### Проблема: Ошибка при запуске

```bash
# Проверка версии Python
python --version

# Проверка установленных пакетов
pip list

# Запуск с подробной информацией об ошибке
python main.py 2>&1 | tee error.log
```

### Проблема: Данные не сохраняются

```bash
# Создание папки вручную
mkdir data

# Проверка прав (Linux/macOS)
chmod 755 data/

# Проверка прав (Windows)
# Проверьте, что папка не защищена от записи
```

## Для разработчиков

### Добавление новой категории

1. В файле `models.py` создайте новый класс, наследующий от `Expense`
2. В файле `expense_manager.py` добавьте категорию в словарь `_get_expense_class()`
3. В файле `gui_app.py` обновите список категорий

### Добавление нового типа графика

1. В файле `chart_builder.py` создайте новый метод
2. В файле `gui_app.py` добавьте кнопку и обработчик
3. Используйте существующие методы для получения данных

### Изменение формата даты

1. В файле `models.py` измените формат в методе `_validate_date()`
2. В файле `gui_app.py` обновите подсказки в диалогах

### Настройка цветовой схемы

В файле `chart_builder.py` измените цвета:

```python
colors = ['#FF6B6B', '#4ECDC4', '#45B7D1', '#96CEB4']
```

## Часто задаваемые вопросы

### Вопрос: Как добавить расход?

**Ответ:** Нажмите кнопку "Добавить расход", заполните поля и нажмите "Добавить".

### Вопрос: Как отфильтровать расходы?

**Ответ:** Используйте панель фильтров: выберите категорию или укажите период.

### Вопрос: Как удалить расход?

**Ответ:** Выберите запись в таблице и нажмите кнопку "Удалить".

### Вопрос: Как построить график?

**Ответ:** Нажмите одну из кнопок: "Круговая", "Столбчатая" или "Динамика".

### Вопрос: Где хранятся данные?

**Ответ:** Данные хранятся в файле `data/expenses.json`.

### Вопрос: Как экспортировать данные?

**Ответ:** Выберите "Файл" -> "Экспорт в JSON" и укажите файл.

### Вопрос: Как импортировать данные?

**Ответ:** Выберите "Файл" -> "Импорт из JSON" и выберите файл.

### Вопрос: Работает ли приложение на Linux?

**Ответ:** Да, приложение работает на Windows, macOS и Linux.

### Вопрос: Нужен ли интернет для работы?

**Ответ:** Нет, приложение работает локально без интернета.

### Вопрос: Как обновить приложение?

**Ответ:** Скачайте новую версию и замените файлы, данные сохранятся.
